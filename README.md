# Logical Calculator 

Десктопное приложение для вычисления логических выражений и построения таблиц истинности.

## Возможности

- **Ввод логических выражений** с помощью виртуальной клавиатуры, поддерживающей символы:
  - `¬` — отрицание (NOT)
  - `∧` — конъюнкция (AND)
  - `∨` — дизъюнкция (OR)
  - `⊕` — исключающее ИЛИ (XOR)
  - `⇒` — импликация (IMPLIES)
  - `≡` — эквивалентность (EQUIV)
  - Переменные: `x`, `y`, `z`, `n`, `m`, `u`, а также константы `0` и `1`

- **Построение таблицы истинности** — автоматическая генерация всех возможных комбинаций значений переменных с вычислением результата для каждой.

- **Статистика** — подсчёт количества положительных и отрицательных исходов, а также определение, является ли выражение тавтологией.

- **Экспорт результатов**:
  - **XLSX** — сохранение таблицы истинности в файл Excel.
  - **Markdown** — копирование таблицы в буфер обмена в формате Markdown.

- **Тёмная и светлая тема** — переключение одной кнопкой.

## Сборка и запуск

### Требования

- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) или новее

### Локальный запуск

```bash
git clone https://github.com/Yarikbot34/LogicalCalculator.git
cd LogicalCalculator
dotnet run --project "Logical calculator"
```
